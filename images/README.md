# Images — how to add your own photos

The site works now with simple drawings (SVG files). To use your own photos, upload a
**.jpg** with exactly the file name below into the same folder. The site will use your photo
automatically. You don't need to change any code, and the drawing stays as a backup.

| Where it shows | Upload this file | Best size |
|---|---|---|
| Home page top banner (behind the headline, darkened) | `images/hero.jpg` | 1920 × 900 px |
| About page photo (office, warehouse, packed parts) | `images/about.jpg` | 1600 × 1000 px (8:5) |
| Engine parts | `images/categories/engine.jpg` | 800 × 600 px (4:3) |
| Ignition & spark plugs | `images/categories/ignition.jpg` | 800 × 600 px |
| Filters | `images/categories/filters.jpg` | 800 × 600 px |

Tips:
- Use lowercase file names ending in `.jpg` (not `.JPG`, `.jpeg` or `.png`).
- Keep each photo under about 200 KB so the site stays fast on phones. You can shrink
  photos for free at https://squoosh.app (choose MozJPEG, quality around 75).
- Only use photos you took yourself or have the rights to. Don't use photos with car brand logos.

Other files in this folder (you can leave these as they are):
- `og-image.png` is the preview picture shown when someone shares a link on WhatsApp,
  Facebook and similar apps. To replace it, use a 1200 × 630 px PNG with the same name.
- `logo.svg` / `logo.png` are the text logo. `apple-touch-icon.png` is the phone home-screen icon.

How to upload on GitHub: open the folder on github.com → **Add file** → **Upload files** →
drag the photo in → **Commit changes**. The site updates within a few minutes.
